Mini app webviews run inside the MentraOS companion app on the user's phone. The top-right corner of the webview is reserved for the MentraOS capsule menu (≡ / ✕), so your content must stay clear of it.

## The capsule menu

The capsule menu is an overlay that sits on top of your webview. It lets users access app actions and exit the mini app.

| Property | Value |
|----------|-------|
| Size | 73 × 30 px |
| Top offset | 8 px |
| Right offset | 8 px |
| Shape | Pill (fully rounded) |

Don't place interactive elements like buttons, menus, tabs, navigation actions, floating actions, or popovers behind the capsule. They won't be tappable.

## Using the SDK

`@mentra/react` exposes the capsule's bounding rect and a derived `safeAreaTop` value so your layout can adapt without hardcoding pixel values. Outside MentraOS (e.g. in a browser during development), the rect is `null` and `safeAreaTop` is `0`, so your app renders normally.

### `useCapsuleMenu` hook

Most apps just need enough top padding to clear the capsule:

```tsx
import { useCapsuleMenu } from "@mentra/react"

function MyScreen() {
  const { safeAreaTop } = useCapsuleMenu()

  return (
    <div style={{ paddingTop: safeAreaTop }}>
      <h1>Hello world</h1>
    </div>
  )
}
```

`safeAreaTop` equals `rect.bottom + 8` when running inside MentraOS, and `0` otherwise.

### `getCapsuleMenuRect()`

If you need fine-grained control (e.g. positioning a header beside the capsule), read the full rect:

```tsx
import { getCapsuleMenuRect } from "@mentra/react"

const rect = getCapsuleMenuRect()
if (rect) {
  // rect.top, rect.right, rect.bottom, rect.left, rect.width, rect.height
}
```

The `CapsuleMenuRect` type:

```ts
interface CapsuleMenuRect {
  top: number
  right: number
  bottom: number
  left: number
  width: number
  height: number
}
```

### Reading the rect without the SDK

The MentraOS app injects a `window.MentraOS` object into every mini app webview before content loads. You can read the capsule rect directly if you aren't using `@mentra/react`:

```ts
if (window.MentraOS?.capsuleMenu) {
  const { top, right, bottom, left, width, height } = window.MentraOS.capsuleMenu
}
```

`window.MentraOS` also includes `platform` (`"ios"` or `"android"`) and a `capabilities` array.
