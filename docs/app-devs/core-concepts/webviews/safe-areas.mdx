Mini app webviews run inside the MentraOS companion app on the user's phone. There are two areas of the screen you need to keep clear of: the capsule menu at the top right, and the system navigation at the bottom.

## The capsule menu

The capsule menu floats over the top-right corner of your webview. It has the ellipsis (≡) and close (✕) buttons that let users access app actions and leave your mini app.

| Property | Value |
|----------|-------|
| Size | 73 × 30 px |
| Top offset | 8 px |
| Right offset | 8 px |
| Shape | Pill (fully rounded) |

Anything you put behind it won't be tappable. Keep buttons, menus, tabs, and navigation actions out of that corner.

## Bottom system navigation

On Android, MentraOS renders your webview above the system navigation bar (gesture bar or 3-button nav), so your content won't end up behind it.

On iOS, you can use the standard CSS environment variable if you need to clear the home indicator:

```css
padding-bottom: env(safe-area-inset-bottom);
```

Either way, don't put important buttons or tab bars right at the bottom edge. Give them some breathing room.

## Using the SDK

`@mentra/react` gives you the capsule's position so you can adjust your layout without hardcoding pixel values. When your app runs outside MentraOS (like in a browser during development), the values fall back to safe defaults and your layout renders normally.

### `useCapsuleMenu` hook

Most apps just need top padding to clear the capsule:

```tsx
import { useCapsuleMenu } from "@mentra/react"

function MyScreen() {
  const { safeAreaTop } = useCapsuleMenu()

  return (
    <div style={{ paddingTop: safeAreaTop }}>
      <h1>Hello world</h1>
    </div>
  )
}
```

`safeAreaTop` is `rect.bottom + 8` inside MentraOS, `0` otherwise.

### `getCapsuleMenuRect()`

If you need more control (e.g. positioning a header next to the capsule), grab the full rect:

```tsx
import { getCapsuleMenuRect } from "@mentra/react"

const rect = getCapsuleMenuRect()
if (rect) {
  // rect.top, rect.right, rect.bottom, rect.left, rect.width, rect.height
}
```

The `CapsuleMenuRect` type:

```ts
interface CapsuleMenuRect {
  top: number
  right: number
  bottom: number
  left: number
  width: number
  height: number
}
```

### Without the SDK

MentraOS injects a `window.MentraOS` object into every mini app webview before your content loads. You can read the capsule rect directly:

```ts
if (window.MentraOS?.capsuleMenu) {
  const { top, right, bottom, left, width, height } = window.MentraOS.capsuleMenu
}
```

`window.MentraOS` also has `platform` (`"ios"` or `"android"`) and a `capabilities` array.
